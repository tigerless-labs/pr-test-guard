# PR Test Guard v0.6.0

Version `0.6.0` makes GitHub Actions adoption quieter, more predictable, and
easier to compose with downstream workflow steps.

## What Changed

- Added stable `PR Test Guard / PTGxxx` titles to warning and error annotations.
- Added independent workflow-command escaping for annotation properties and
  messages, including safe file paths containing `%`, `,`, or `:`.
- Added `github.annotations.max_total` and
  `github.annotations.max_per_rule` configuration.
- Bounded annotations to 50 total and 10 per rule by default, with error-level
  findings selected before warnings and deterministic rule/path/line ordering.
- Reported total and per-rule annotation omissions in the GitHub job summary.
- Kept GitHub Summary tables and JSON reports complete when annotation limits
  omit workflow commands.
- Added composite Action outputs for `status`, `findings-count`,
  `warning-count`, `error-count`, and `report-path`.
- Added explicit `operational-error` status output when Action validation or the
  checker returns an operational failure.
- Added YAML, JSON, and TOML configuration coverage plus focused annotation,
  escaping, prioritization, zero-limit, summary, JSON, and output-contract tests.

## Configuration

```yaml
github:
  annotations:
    max_total: 50
    max_per_rule: 10
```

Both values are non-negative integers. `0` disables the corresponding
annotation scope. Limits affect only GitHub workflow-command annotations; they
do not suppress findings, change policy exit codes, truncate summary tables, or
remove findings from JSON output.

## Action Outputs

```yaml
- uses: tigerless-labs/pr-test-guard@v0.6.0
  id: guard
  with:
    base: origin/${{ github.base_ref }}

- if: always() && steps.guard.outputs.status == 'advisory'
  env:
    FINDINGS: ${{ steps.guard.outputs.findings-count }}
  run: echo "$FINDINGS finding(s) need review"
```

`status` is `clean`, `advisory`, `failed`, or `operational-error`. The count
outputs reflect the final policy-filtered result.

## Compatibility

- Detection rules, finding schemas, policy exit codes, and existing Action
  inputs are unchanged.
- Valid `0.5.1` configuration remains valid; normalized policy JSON now includes
  the effective GitHub annotation limits.
- Default GitHub annotation delivery is now bounded. Full findings remain
  available in the job summary and JSON report.
- Text and JSON CLI output behavior is unchanged.
